# MetricsDash — Svelte Analytics Dashboard

## Tech Stack
- SvelteKit 1.x
- Chart.js (charting library)
- Tailwind CSS
- MongoDB (data backend)

## Setup
```bash
npm install
npm run dev
```

> Ensure the Chart.js version installed is compatible with the API syntax used in `src/lib/components/`. Check the Chart.js changelog if charts do not render.

## Project Structure
```
src/routes/           SvelteKit pages
src/lib/components/   Chart and UI components
```
