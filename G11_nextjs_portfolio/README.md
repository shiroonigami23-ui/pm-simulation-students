# PortfolioX — Next.js Portfolio Site

## Tech Stack
- Next.js 13 (App Router)
- React 18
- Tailwind CSS
- FontAwesome icons

## Setup
```bash
npm install
npm run dev
```

> If `npm install` fails on icon packages, check `.npmrc` for required configuration.

## Project Structure
```
src/app/              App Router pages
src/components/       UI components
public/               Static assets
```
